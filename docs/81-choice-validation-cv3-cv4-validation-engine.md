# Choice Validation CV3 + CV4 — Validation Engine

Approved source is immutable. Processing requires finalized, non-stale Viva and strict finalized Circular dataset.

Candidate gate: ACTIVE + Viva PASS + finalized Viva result; surviving Written track maps GG/GN→General, TT/T→Technical, GT→Both.

General entry: track only. Technical entry: Registration bachelor subject IN Circular allowed bachelor set AND Registration PRS IN Circular allowed PRS set. Written PRS is not an eligibility authority.

Main code with finalized Circular sub-cadre rows expands to candidate-eligible sub-cadres in sub_serial order. Direct sub-cadre choice is accepted. Repeated output codes are deduplicated while source/detail trail is preserved.

Results are versioned and stored separately from raw source in choice_validation_results and choice_validation_items.
