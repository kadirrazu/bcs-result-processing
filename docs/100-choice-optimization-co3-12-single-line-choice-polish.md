# Choice Optimization CO3.12 — Single-Line Choice Comparison Polish

- Individual OMR detail combines Stage and Meaning into one column.
- Choice Sequence uses a single horizontal lane and never wraps into a second line.
- Batch OMR review uses the same single-line left-to-right #01 → #20 visual lane.
- Horizontal scrolling is used only when viewport width is insufficient, preserving preference-position alignment.
- Choice chips remain fixed-width so source-to-source differences are visually comparable.
