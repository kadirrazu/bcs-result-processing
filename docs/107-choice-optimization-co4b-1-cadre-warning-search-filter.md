# Choice Optimization CO4B.1 — Cadre Warning-Only + Repository Search/Filter

- Historical `cadre` abbreviation is preserved as supplied in the source row.
- Central Cadre/Sub-Cadre master lookup is advisory for Previous BCS repository data.
- A cadre abbreviation not found in the current master namespace produces `CADRE_MASTER_MISMATCH` warning only.
- Warning-only rows remain valid and do not block dataset approval/effective status.
- Blank cadre remains a blocking required-field problem.
- Dataset rows can be searched across registration, candidate/father/mother name, district, SSC/HSC roll, NID and cadre.
- Filters are available for validation status, warning, cadre, SSC year and HSC year.
