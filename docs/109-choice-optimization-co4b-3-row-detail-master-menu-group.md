# Choice Optimization CO4B.3 — Row Detail + Master Data Historical Group

- Each row on a Previous BCS dataset page has a `View` action.
- The row detail page is read-only and shows normalized historical fields, system errors/warnings and the preserved raw source payload.
- The existing Full Dataset tabular page remains available separately.
- Historical records are not edited directly; corrections continue through a new versioned dataset upload.
- `Historical Data` is not a separate top-level navigation menu.
- Inside the existing `Master Data` dropdown, a `Historical Data` section appears below `Registration Masters`, containing `Previous BCS Repository`.
